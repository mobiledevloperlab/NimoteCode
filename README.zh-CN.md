## NimoteCode 是什么？

NimoteCode 是一款面向 Android 与 iOS 的**移动 IDE**与 **SSH IDE**。它把手机或平板变成真实的开发工作区：打开本地项目、在 Android 本地 Linux 中使用内置 Ubuntu，或通过 SSH 连接你的 Mac、Linux 主机或 VPS；在完整编辑器中改代码、在终端里运行命令、审查 Git 变更、预览 Web 项目，并使用内置的 AI 编码 Agent——全部在一个应用内完成。

它面向需要在离开工位后继续推进真实工作的开发者：远程开发、值班应急修复、代码审查，以及移动端 AI 辅助编码。

- **移动 IDE**：在手机/平板上完整运行开发工作区。  
- **远程 SSH 开发**：连接现有 Mac/Linux 主机或 VPS。
- **Android 本地 Linux**：在支持 Android 8+ ARM64/x86_64 的设备上免 root 使用内置 Ubuntu、Bash、Git 和 SSH。
- **内置 AI Agent**：应用自带的编码 Agent 直接在工作区内运行，无需终端、无需安装 CLI，连接自己的 AI Provider 即可使用。  
- **真实开发工具**：编辑器、终端、Git、搜索、诊断、任务与调试。  
- **随时随地的真实开发**：外出时也能继续推进真正项目。

## 核心功能

- 本地、Android 本地 Linux 与 SSH 工作区，覆盖设备本地和远程开发
- Explorer 与完整代码编辑器，支持双栏分屏并排查看两个文件
- 应用内 Web 预览（本地或远程 Web 项目，支持直接预览未保存的 HTML 内容），以及图片与媒体预览
- 终端：执行命令、查看日志、运行测试与已配置 CLI 工具
- Git Source Control：查看状态、Diff、历史并支持审查工作流
- 内置 AI Chat 与 AI 编码 Agent：提供项目感知的辅助与任务执行——自带 AI Provider，无需安装 CLI；在 SSH 工作区还可运行已配置的外部 ACP Agent
- 搜索、诊断、任务、LSP、调试与同步/缓存工作流（按配置可用）

## 内置 AI 编码 Agent（无需安装）

NimoteCode 的 **AI Agent** 是应用的一部分，而不是需要安装在主机上的终端 CLI。给它一个产品需求，它会按一条闭环推进：**规划 → 检查项目 → 编辑文件 → 运行检查 → 修复问题 → 审查 Git 结果**。它直接作用于本地、Android 本地 Linux 或 SSH 工作区，并交回可审查的 Git 变更。

- 无需安装、无需配置 Shell、无需额外的 Agent 运行时。
- 直接作用于你已经打开的项目。
- 在 SSH 工作区中，还可选择已配置的兼容 ACP 外部运行时，例如通过 Claude Code 或 Codex CLI 提供的运行时。
- 你需要连接自己的 AI Provider 与 API Key（BYOK）；NimoteCode 不捆绑模型访问。
- **AI Chat** 适合快速的上下文问答；**AI Agent** 可在按设备计算的 14 天 Pro 试用期间和 Pro 中使用。

## 在终端使用你喜欢的编码工具

NimoteCode 内置的 Agent 无需安装。如果你还想在自己的主机上运行命令行 AI 工具，也可以在本地或 SSH 工作区中使用，包括 [Codex](https://nimotecode.com/zh/codex-from-phone)、[Claude Code](https://nimotecode.com/zh/claude-code-from-phone)、Kimi 等。这些是可选项，与内置 Agent 相互独立。Android 本地 Linux 也可以运行你自行安装的工具。对 Codex 与 Claude Code 的移动工作流，NimoteCode 将 CLI、项目文件、终端输出与 Git 审查放在一起。产品不捆绑模型订阅，请按需配置自己的模型提供商、账号或 BYOK 接入。

## 1.1.7 更新内容

**1.1.7（Build 41）现已发布**。本次更新要点：

- **Android 本地 Linux 工作区。** 在支持的 ARM64 与 x86_64 Android 设备上运行内置 Ubuntu 环境，包含 Bash、Git 与 SSH，无需 root 权限。仅 Android 支持，iOS 不提供此功能。
- **HTML 快照预览。** 直接预览当前 HTML 编辑内容（含未保存修改），支持工作区内的 CSS、JavaScript 与图片资源。
- **一键打开链接。** 终端、AI 回复和工具输出中的网页链接提供统一的浏览器入口。
- **外部 ACP Agent。** 在 SSH 工作区中，与内置 Agent 一起选择并运行兼容 ACP 的外部 Agent。
- **统一 SSH 登录环境。** Terminal、ACP Server、Agent 子进程、Tasks、Debug、语言服务、Git 与外部 CLI 共享同一套远程环境解析机制，正确继承您的真实 Shell 与自定义变量。
- **更安全的诊断信息。** API Key、Token、Secret 与密码等敏感信息会在日志与 Agent 启动诊断中自动脱敏。

完整的改进与修复清单见[1.1.7 发布说明](https://nimotecode.com/zh/releases/)。

## 常见问题

### NimoteCode 是完整 IDE，还是只是一个 SSH 客户端？

NimoteCode 是完整的移动 IDE，而不只是 SSH 客户端。它可以打开本地项目、使用 Android 本地 Linux 或打开 SSH 工作区，并把 Explorer、编辑器、终端、Git 工作流、AI 辅助和诊断面板放在同一个项目上下文中。

### NimoteCode 免费吗？

免费。免费版包含本地、Android 本地 Linux 与 SSH 工作区、编辑器、基础终端、Git 审查、AI Chat 和 Tasks。本地 Linux 需要 Android 8+ 的 ARM64 或 x86_64 64 位设备，iOS 不提供此功能。AI Agent 与远程搜索可在按设备计算的 14 天 Pro 试用期间和 Pro 中使用。

### AI Agent 是运行在终端里，还是需要安装 CLI？

都不是。AI Agent 内置于应用，直接运行在本地、Android 本地 Linux 或 SSH 工作区中。你无需安装 CLI，也无需配置 Shell Agent，只需连接自己的 AI Provider 与 API Key（BYOK）。

### NimoteCode 支持 iPhone 和 iPad 吗？

支持。NimoteCode 已上架 [App Store](https://apps.apple.com/app/nimotecode-ssh-client-ide/id6776158253)。Android 本地 Linux 是平台专属功能，iPhone 与 iPad 不提供。

### 可以配置哪些 AI Provider？

应用内置 14 个 Provider 模板，并支持兼容的自定义端点。Provider 的可用性、模型访问和费用由你自己的 Provider 账户与设置决定。

### NimoteCode 是开源的吗？

不是。NimoteCode 目前为**闭源**产品。本仓库是官网与公开内容仓库，并非应用源码仓库。

### NimoteCode 与 Termius、Blink Shell 或 Claude Code 有何不同？

SSH 客户端侧重远程访问，终端 AI 工具侧重单一 Agent。NimoteCode 将编辑器、远程工作区、终端、Git、预览和内置 AI Agent 整合进同一个移动开发环境，让你可以在同一处完成检查、编辑、运行、验证与审查。
